# Illegal Chips

Visual recreation of [illegalchips.com](https://illegalchips.com/) (MSCHF DROP #61), built with Next.js.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Assets (images, fonts, copy) are sourced from the original site for fidelity.
- The shop UI mirrors the original sold-out state.
- Routes: `/`, `/faq`, `/manifesto`.
